# 请求链路优化与验证

实施基线：`f13a344`。继续使用单进程 FastAPI、SQLite 和单容器部署。

本次播放策略与线路测速补充：本服务不转码，旧 continuous 配置兼容为原样 proxy，移除 FFmpeg 依赖和 4 会话限制。播放解析、HLS、文件中转、预检、测速独立连接池，容量与缓冲、缓存、排队超时、失败冷却均可配置；连接额度没有固定上限，不做用户配额或每用户限速。默认播放解析 32、HLS 64、文件 64、预检 16、测速 16。保存配置让新请求使用新资源，旧连接完成后退役。

同地址的并发预检合并；连接池、同源锁、播放页面额度等待时耗尽预算不记为源故障，上游真实超时仍记失败。普通 /play 默认按外部客户端处理出口限制；网关增加 strict_redirect，禁止中转回退，成功选中的中转源绑定会话地址。影片详情支持所有线路并行采样、逐条返回结果和停止，测速不修改已选线路、失败记录或健康排序。

新增本地 HTTP 验证同时保持 50 条文件媒体连接时，HLS、预检与测速资源仍可使用，变更配置不切断已有连接；同地址 50 个预检只发起一次上游请求。它验证资源隔离和生命周期，不代表生产服务器可持续承载 50 路视频码率。测速使用有限采样，包含媒体首字节等待，服务器/代理带宽由所有并行线路共享。

## 最终行为

### 播放

- 从 HTTP 入口覆盖数据库、找源、刷新锁、连接排队与清单返回的总预算；响应开始后使用上游停滞超时，不把整部影片限制在 20 秒内。
- `resolve_attempt_timeout` 默认 6 秒，给备用源留出机会。多线路源允许两次尝试额度，仍受总预算约束。播放碰到挑战优先试镜像，解题在后台恢复 Cookie。
- 每个播放清单固定源、线路与直链快照，分片使用会话缓存；会话和签名密钥可在服务重启后恢复。旧的无会话 `/hls` 地址仍可访问。
- 单线路相对分片中转使用较短有效期门槛；跨目录、带独立签名的资源以及多线路源保留完整时长要求，避免短缓存导致中途失效。
- 清单按直链、请求头、代理及指纹缓存 15 秒，容量 128；并发读取合并，最后一个等待方取消后关闭上游。画质探测复用清单缓存。

### 资源与数据库

- 每代连接池分别为后台 32、播放解析 8、中转 16；媒体缓冲每连接最多 512 KiB，满时暂停 curl，消费后恢复。断开与超时释放上游及连接额度。
- 代理/指纹修改后，旧会话等待已接受请求结束再关闭；退出时清理后台解题、缓存加载、画质探测及退役任务。
- SQLite 写入、快速读取、批量查询分别使用连接。事务内部读取仍在原事务连接，取消事务也执行回滚清理。
- 分类、标签、女优保留原 JSON；关联索引由数据库触发器维护，包括插入、更新、下架和删除。候选聚合使用覆盖索引；发行日期双向排序使用表达式索引。
- 统计缓存 3 秒、候选缓存 30 秒，业务数据写入使缓存失效；客户端保留查询缓存和取消信号。JSON API 压缩，SSE 与视频中转不进入压缩层。

### 任务与订阅

- 列表完整性只在必要列表页全部成功后成立。列表完成即可归并与后续增量；详情和封面继续后台处理，列表失败继续阻断确认。
- 只剩元数据任务时允许下一轮列表，但删除订阅仍检查所有后台任务。排除库确认使用实际开始时间；增量重跑本页不会把本次刚加入的片当成停止依据。
- 单片刷新、补源和批量归属操作返回 202 与 `job_id`；全库补全、画质探测、补源先持久化操作，再后台分批入队。
- 封面独立重试，任务结束可显示“部分失败”。同部影片的输出串行，原子写入使用独立临时文件。
- 重写、重新归库和核对持久化游标；扫描分批暂存，完成后原子发布索引。暂停/取消在条目或批次之间生效，未完成的扫描保留之前已发布结果。

### 观测

- 返回 `X-Request-ID`、`Server-Timing`；日志携带请求编号并脱敏 URL，文件写入移到后台线程。
- 最近 15 分钟、每阶段最多 512 个样本，显示 P50/P95/最大值；包括读取、批量查询、刷新排队、连接排队、上游响应、清单与真实中转首字节。
- 显示活动连接、缓冲字节、传输字节、上游断流、客户端断开和日志缺口。SSE 使用进程实例与游标恢复，重启发送 reset，溢出提示 gap。
- `/healthz` 检测进程；`/readyz` 检查数据库、worker 与 scheduler。暂停不算故障。

## 升级与接口变化

- 自动迁移到 SQLite v12，新增筛选索引、扫描暂存和播放会话；本轮未对真实业务库执行迁移。
- 历史最后一次全量任务有失败列表页的订阅会重新标为未初始化，需要重跑或通过现有页面手动确认。原有影片、输出与失败记录保留。
- `POST /api/videos/{slug}/refresh`、`POST /api/videos/{slug}/probe`、`POST /api/videos/batch` 改为异步返回 `{job_id}`。脚本可通过 `GET /api/jobs/{job_id}` 跟进，影片详情通过 `GET /api/videos/{slug}` 读取。
- 有界中转适配测试版本 `curl_cffi 0.16.3`，依赖限制为 `>=0.16.3,<0.17`；升级该依赖时运行真实本地 HTTP 背压测试。

## 合成负载对比

同一份 200,000 部影片、每部一个源和三类元数据，基线运行后关闭，再迁移原库运行当前实现。每项三次取中位数，单位 ms。

| 操作 | 基线 | 当前 |
|---|---:|---:|
| 默认列表 | 8.92 | 9.72 |
| 发行日期排序 | 86.81 | 9.09 |
| LIKE 关键词搜索 | 131.54 | 128.71 |
| 女优筛选 | 304.89 | 1.63 |
| 候选聚合：冷缓存 | 1346.32 | 202.98 |
| 候选聚合：热缓存 | 1424.21 | 1.12 |
| 聚合查询并发时按 slug 读取 | 1122.14 | 1.83 |

这份合成库迁移耗时约 8.55 秒。发行日期查询计划使用 `videos_release_desc`。全文搜索仍沿用 LIKE；当前合成规模已满足页面目标，FTS 按真实规模和检索语义再评估。

复测：`.venv/Scripts/python -B scripts/benchmark.py --rows 200000 --baseline-ref f13a344`。
